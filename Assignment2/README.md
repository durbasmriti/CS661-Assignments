## CS661 Assignment-2 | Group 6

This script builds an interactive interface that combines a 3D isosurface view with a related histogram. Both windows are synchronized with a slider covering the entire range of scalar values from a 3D volume data set. The slider is adjusted to update the view in real time. A "Reset" control, unique to this visualization, enables users to restore the slider and visualizations to their initial position. The histogram is plotted with 30 bins.

To run the code, open the app.ipynb file and run the cells.

Note: Once the interactive interface is started, clicking the reset control might take a short time because the initial state is restored.
